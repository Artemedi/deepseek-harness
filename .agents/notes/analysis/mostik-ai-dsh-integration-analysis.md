### 1.1 Цель анализа

### 1.2 Источники
- **mostik.ai/read-more** — официальный сайт проекта
- **t.me/data_secrets/9882** — публикация в Telegram-канале

## 2. Анализ с разных точек зрения

- Поддержка локального и облачного развертывания
- API для программного доступа к функционалу

- Вероятно, основана на современных LLM-технологиях
- Поддержка кастомных workflow и бизнес-процессов
- Интеграция с внешними сервисами
- Система визуального построения ИИ-агентов

#### Возможности интеграции с DSH:
- Создание кастомного провайдера субагентов
- Разработка LLM-адаптера для моделей mostik.ai

## 3. Техническая оценка интеграции

### 3.1 Архитектура DSH

DSH имеет модульную плагин-архитектуру с следующими ключевыми компонентами:

1. **Subagent seam** — поддерживает регистрацию множества провайдеров субагентов
2. **LLM adapters** — позволяет подключать новых провайдеров моделей
3. **Tools system** — для создания кастомных инструментов
4. **Skills system** — для расширения функционала
5. **Plugin system** — для добавления новых возможностей

### 3.2 Существующие провайдеры субагентов DSH:

1. **spawn-in-process** — внутрипроцессный, дешёвый транспорт
2. **dsh-sdk** — out-of-process через stdio JSON-RPC
3. **acp** — out-of-process через Agent Client Protocol
4. **claude-code** — интеграция с Claude Code
5. **codex** — интеграция с Codex
6. **fork-in-process** — форк внутри процесса

### 3.3 Возможные подходы к интеграции

#### Подход 1: Кастомный провайдер субагентов
Создание нового пакета `dsh-subagent-mostik`:
- Реализация интерфейса `SubagentProvider`
- Поддержка всех стартовых возможностей
- Интеграция с mostik.ai API

#### Подход 2: LLM-адаптер
Разработка адаптера для моделей mostik.ai:
- Наследование от `LlmAdapter`
- Маппинг API mostik.ai в `StreamChunk`
- Обработка аутентификации и ошибок

#### Подход 3: Набор инструментов
Создание инструментов для работы с mostik.ai:
- Управление агентами
- Координация через модели коммуникаций
- Интеграция с платформой

## 6. Заключение

mostik.ai и DeepSeek Harness представляют собой совместимые проекты, которые могут создать мощное интегрированное решение для рынка ИИ-агентов. Техническая реализация возможна через стандартные механизмы расширения DSH. Основные вызовы связаны с регуляторными требованиями и стратегическим позиционированием. Интеграция может создать конкурентное преимущество на российском рынке и потенциально на международных рынках.
